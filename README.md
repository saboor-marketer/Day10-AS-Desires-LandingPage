# AS Desires

A responsive dessert-brand landing page built with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it with `npm run preview`.

## Before launch

- Update `src/data/siteConfig.ts` with confirmed product names, descriptions, prices, variants, and availability.
- Add a verified email, phone number, WhatsApp number, HTTPS order URL, address, or social profiles in `brandConfig.contact` as appropriate. Unconfigured contact items stay hidden.
- Replace the `.example` canonical and Open Graph URLs in `index.html` with the production domain.
- Review the sample product photography and menu copy against the business's real offerings.
